Install Git

Setup
1
Install Git on Your OS
macOS
# Option A: Xcode CLI tools
xcode-select --install

# Option B: Homebrew
brew install git
Ubuntu / Debian
sudo apt update
sudo apt install git -y
Fedora / RHEL
sudo dnf install git -y
Windows
winget install --id Git.Git -e --source winget
2
Verify Installation
Terminal
git --version
ssh -V
Expected: git version 2.x.x

Configure Git

Setup
3
Set Your Identity
Terminal
git config --global user.name "Your Full Name"
git config --global user.email "you@example.com"
Use the same email as your GitHub profile.
4
Set Defaults
Terminal
# Default branch = main
git config --global init.defaultBranch main

# Default editor
git config --global core.editor "code --wait"   # VS Code

# Colored output
git config --global color.ui auto

# Pull strategy (cleaner history)
git config --global pull.rebase true
5
Verify Config
Terminal
git config --global --list

Config lives at ~/.gitconfig (global) and .git/config (per-repo).

SSH Key Setup

Setup
6
Check Existing Keys
Terminal
ls -al ~/.ssh

Look for id_ed25519 or id_rsa. If found, skip to step 8.

7
Generate SSH Key
Terminal
ssh-keygen -t ed25519 -C "you@example.com"

Press Enter for default path. Set a passphrase or press Enter for none.

~/.ssh/
├── id_ed25519 ← private key (never share)
└── id_ed25519.pub ← public key (goes on GitHub)
Legacy systems: use ssh-keygen -t rsa -b 4096 -C "you@example.com"
8
Start SSH Agent & Add Key
macOS / Linux
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
Windows (Admin PowerShell)
Get-Service ssh-agent | Set-Service -StartupType Automatic
Start-Service ssh-agent
ssh-add $env:USERPROFILE\.ssh\id_ed25519
~/.ssh/config
Host github.com
  AddKeysToAgent yes
  UseKeychain yes
  IdentityFile ~/.ssh/id_ed25519
Terminal
ssh-add --apple-use-keychain ~/.ssh/id_ed25519
9
Copy Public Key
Cross-platform
# macOS
pbcopy < ~/.ssh/id_ed25519.pub

# Linux
xclip -selection clipboard < ~/.ssh/id_ed25519.pub

# Windows
Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub | Set-Clipboard

# Or just print it
cat ~/.ssh/id_ed25519.pub

Add Key to GitHub & Test

Setup
10
Add SSH Key on GitHub

github.com/settings/keys → New SSH key → paste your public key → Add SSH key

One SSH key = one GitHub account. Same key on two accounts causes errors.
11
Test SSH Connection
Terminal
ssh -T git@github.com
Expected: Hi username! You've successfully authenticated...

Setup

Clone an Existing Repo

git clone git@github.com:your-username/repo-name.git

Start a New Project Locally
Terminal

Daily Git Workflow

Workflow
14
The Basic Cycle
Terminal
# 1. Check status
git status

# 2. Stage changes
git add file.txt           # one file
git add .                  # everything in current dir
git add -A                 # everything everywhere
git add -p                 # interactively pick hunks

# 3. Commit
git commit -m "Short description of the change"

# 4. Push to remote
git push
15
See What Changed
Terminal
git diff                   # unstaged changes
git diff --staged          # staged changes
git diff main..feature     # between branches
git log --oneline --graph  # compact visual history
git log -5                 # last 5 commits

Branching

Workflow
16
Create, Switch & List
Terminal
# Create and switch
git switch -c feature/login-page
# or: git checkout -b feature/login-page

# List branches
git branch            # local
git branch -a         # local + remote

# Switch
git switch main

# Delete
git branch -d feature/login-page       # safe
git branch -D feature/login-page       # force

# Push new branch to remote
git push -u origin feature/login-page

# Delete remote branch
git push origin --delete feature/login-page

Merging & Rebasing

Workflow
17
Merge, Rebase & Resolve Conflicts
Terminal
# Merge
git checkout main
git merge feature/login-page

# Rebase (linear history)
git checkout feature/login-page
git rebase main

# Resolve conflicts
git add resolved-file.txt
git commit                          # for merge
git rebase --continue               # for rebase
git rebase --abort                  # abandon

Undoing Things

Workflow
18
Restore, Reset & Revert
Terminal
# Unstage a file
git restore --staged file.txt

# Discard changes to a file
git restore file.txt

# Amend last commit message
git commit --amend -m "Better message"

# Amend last commit with new files
git add forgotten-file.txt
git commit --amend --no-edit

# Undo last commit (keep changes staged)
git reset --soft HEAD~1

# Undo last commit (unstage changes)
git reset HEAD~1

# Undo last commit (DESTRUCTIVE)
git reset --hard HEAD~1

# Safe revert (new undo commit)
git revert <commit-hash>

Stashing

Workflow
19
Shelve Changes Temporarily
Terminal
git stash                     # stash tracked changes
git stash -u                  # include untracked
git stash save "WIP: login"  # with a label

git stash list                # see all stashes
git stash pop                 # apply & remove
git stash apply               # apply & keep
git stash drop stash@{0}     # delete specific
git stash clear               # delete all

Working with Remotes

Workflow
20
Manage Remotes
Terminal
git remote -v                                          # list
git remote add origin git@github.com:user/repo.git     # add
git remote add upstream git@github.com:orig/repo.git   # upstream
git remote set-url origin git@github.com:user/repo.git # change URL

git fetch origin              # download without merge
git pull origin main          # fetch + merge
git push origin main          # push
git push --force-with-lease origin feature  # safe force push

Pull Requests

Advanced
21
Fork → Branch → PR Workflow
Terminal
# 1. Fork the repo on GitHub, then clone your fork
git clone git@github.com:your-username/forked-repo.git
cd forked-repo

# 2. Add original repo as upstream
git remote add upstream git@github.com:original-owner/repo.git

# 3. Create a feature branch
git checkout -b fix/typo-in-readme

# 4. Make changes, commit, push
git add .
git commit -m "Fix typo in README"
git push -u origin fix/typo-in-readme

# 5. Open PR on GitHub: Compare & pull request

# 6. Keep your fork in sync
git fetch upstream
git checkout main
git merge upstream/main
git push origin main

Tags

Advanced
22
Create & Push Tags
Terminal

git tag -a v0.9.0 <hash> -m "Beta"                  # tag past commit

git tag -d v1.0.0                        # delete local

Useful Aliases

Advanced
24
Add Shortcuts to ~/.gitconfig
~/.gitconfig [alias]
[alias]
    s   = status
    co  = checkout
    br  = branch
    ci  = commit
    lg  = log --oneline --graph --decorate --all
    last = log -1 HEAD --stat
    unstage = restore --staged
    undo = reset HEAD~1
    amend = commit --amend --no-edit
    wip = !git add -A && git commit -m 'WIP'
Terminal
git config --global alias.s "status"
git config --global alias.lg "log --oneline --graph --decorate --all"

GPG Signing Commits

Advanced
25
Set Up Verified Commits
Terminal
# Generate GPG key
gpg --full-generate-key

# Find your key ID
gpg --list-secret-keys --keyid-format=long
# Look for: sec rsa4096/ABCDEF1234567890

# Tell Git to use it
git config --global user.signingkey ABCDEF1234567890
git config --global commit.gpgsign true

# Export public key → add to GitHub Settings
gpg --armor --export ABCDEF1234567890

Multiple GitHub Accounts

Advanced
26
Generate Separate Keys & SSH Config
Terminal
# Generate separate keys
ssh-keygen -t ed25519 -C "personal@email.com" -f ~/.ssh/id_ed25519_personal
ssh-keygen -t ed25519 -C "work@company.com" -f ~/.ssh/id_ed25519_work
~/.ssh/config
# Personal
Host github.com-personal
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_personal

# Work
Host github.com-work
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_work
Terminal
# Clone with alias
git clone git@github.com-personal:user/repo.git
git clone git@github.com-work:org/repo.git

# Set per-repo identity
cd work-repo
git config user.name "Work Name"
git config user.email "work@company.com"

SSH Troubleshooting

Advanced
ProblemFix
Permission denied (publickey)Run ssh-add ~/.ssh/id_ed25519 and verify key is on GitHub
Agent not runningeval "$(ssh-agent -s)"
Wrong key usedCheck ssh -vT git@github.com
Firewall blocks port 22Use SSH over port 443 (below)
Key not persisting (macOS)Add UseKeychain yes to ~/.ssh/config
27
SSH over Port 443 & Debug
~/.ssh/config (firewall bypass)
Host github.com
  HostName ssh.github.com
  Port 443
  User git
  IdentityFile ~/.ssh/id_ed25519
Terminal
# Test port 443
ssh -T -p 443 git@ssh.github.com

# Verbose debug
ssh -vvv git@github.com

# Fix file permissions
chmod 700 ~/.ssh
chmod 600 ~/.ssh/id_ed25519
chmod 644 ~/.ssh/id_ed25519.pub
chmod 644 ~/.ssh/config
