Install Git

All Users
1
Install Git on Windows

Open PowerShell and install with Windows Package Manager:

PowerShell
winget install --id Git.Git -e --source winget

Or download from git-scm.com

Close and reopen PowerShell after install so git is in your PATH.
2
Verify Git Installation
PowerShell
git --version
Expected: git version 2.x.x.windows.x
3
Verify SSH Is Available
PowerShell
ssh -V
Expected: OpenSSH_for_Windows_9.x

Configure Git

All Users
4
Set Your Identity
PowerShell
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
Use the same email as your GitHub profile.
5
Set Default Branch Name
PowerShell
git config --global init.defaultBranch main
6
Set Default Editor (Optional)
PowerShell
# VS Code
git config --global core.editor "code --wait"

# Notepad
git config --global core.editor "notepad"

SSH Key Setup

Single
7
Create .ssh Directory
PowerShell
if (!(Test-Path "$env:USERPROFILE\.ssh")) {
    New-Item -ItemType Directory -Path "$env:USERPROFILE\.ssh"
}
8
Generate SSH Key
PowerShell
ssh-keygen -t ed25519 -C "your.email@example.com" -f "$env:USERPROFILE\.ssh\my_github_key"

Enter a passphrase when prompted or press Enter to skip.

C:\Users\YourName\.ssh\
├── my_github_key private key
└── my_github_key.pub public key
9
Start SSH Agent

As Administrator:

Admin
Get-Service ssh-agent | Set-Service -StartupType Automatic
Start-Service ssh-agent

Then normally:

PowerShell
ssh-add "$env:USERPROFILE\.ssh\my_github_key"
ssh-add -l
10
Create SSH Config
PowerShell
New-Item -ItemType File -Path "$env:USERPROFILE\.ssh\config" -Force
notepad "$env:USERPROFILE\.ssh\config"

Paste this and save:

~/.ssh/config
Host github.com
    HostName github.com
    User git
    IdentityFile ~/.ssh/my_github_key
    AddKeysToAgent yes

Add Key to GitHub

All Users
11
Copy Public Key
PowerShell
Get-Content "$env:USERPROFILE\.ssh\my_github_key.pub" | Set-Clipboard
12
Add Key on GitHub

github.com/settings/keys > New SSH key > paste your key > Add SSH key

One SSH key = one GitHub account. Same key on two accounts causes errors.

Test and Use

All Users
13
Test Connection
PowerShell
ssh -T git@github.com
Expected: Hi username! You've successfully authenticated...
14
Clone a Repo
PowerShell
git clone git@github.com:yourusername/your-repo.git
15
Create a New Project
PowerShell
mkdir my-project
cd my-project
git init
git remote add origin git@github.com:user/repo.git
git add .
git commit -m "first commit"
git push -u origin main

Multiple Accounts

Multi

Each GitHub account needs its own SSH key and host alias.

16
Generate Separate Keys
PowerShell
# Personal
ssh-keygen -t ed25519 -C "personal@email.com" -f "$env:USERPROFILE\.ssh\github_personal"

# Work
ssh-keygen -t ed25519 -C "work@company.com" -f "$env:USERPROFILE\.ssh\github_work"
17
Add Both Keys
PowerShell
ssh-add "$env:USERPROFILE\.ssh\github_personal"
ssh-add "$env:USERPROFILE\.ssh\github_work"
18
SSH Config with Aliases
~/.ssh/config
# Personal
Host github.com-personal
    HostName github.com
    User git
    IdentityFile ~/.ssh/github_personal
    AddKeysToAgent yes

# Work
Host github.com-work
    HostName github.com
    User git
    IdentityFile ~/.ssh/github_work
    AddKeysToAgent yes
19
Add Keys to Correct Accounts
PowerShell
Get-Content "$env:USERPROFILE\.ssh\github_personal.pub" | Set-Clipboard
# Add to personal GitHub, then:
Get-Content "$env:USERPROFILE\.ssh\github_work.pub" | Set-Clipboard
# Add to work GitHub
20
Test Both
PowerShell
ssh -T git@github.com-personal
ssh -T git@github.com-work
21
Clone with Alias
PowerShell
git clone git@github.com-personal:user/repo.git
git clone git@github.com-work:org/repo.git
22
Per-Repo Identity
PowerShell
cd work-repo
git config user.name "Work Name"
git config user.email "work@company.com"
.gitconfig
[user]
    name = Personal Name
    email = personal@email.com

[includeIf "gitdir:F:/Work/"]
    path = ~/.gitconfig-work
.gitconfig-work
[user]
    name = Work Name
    email = work@company.com

Troubleshooting

PowerShell
ssh -vT git@github.com
ssh-add -D
ssh-add "$env:USERPROFILE\.ssh\my_github_key"
PowerShell
Get-Service ssh-agent
ssh-add -l
ssh-keygen -lf "$env:USERPROFILE\.ssh\my_github_key.pub"
Admin
Get-Service ssh-agent | Set-Service -StartupType Automatic
Start-Service ssh-agent
